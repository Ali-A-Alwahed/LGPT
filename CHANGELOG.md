# Changelog

All notable changes to the LGPT License are documented here.

The format is based on
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project
adheres to
[Semantic Versioning](https://semver.org/spec/v2.0.0.html) for the license
itself.

**A license version that has been released is never edited in place.** Changes
are always prospective: a project that already distributed code under 1.0 keeps
the 1.0 terms forever. If a change is material enough to alter obligations for
existing recipients, it is a new major version and existing code does not
inherit it.

## [1.0] — 2026

Initial release. 31 sections.

### Granted

- Unrestricted use for any purpose, including commercial (§3).
- Modification, forking, and derivative works (§3, §8).
- Static and dynamic linking, and embedding as a component (§3.8, §10).
- Commercial distribution, including charging any price (§3.11–3.12).
- Sublicensing portions of a larger work (§3.13).
- Private, unpublished modifications (§3.14).
- Use in any field, with no field-of-use restriction (§4).
- Modification for repair, security research, and interoperability (§11).
- An express worldwide patent license with a litigation-termination clause (§15).

### Required

- Reasonable and conspicuous attribution (§6).
- Preservation of copyright and license notices (§7).
- Marking substantial modifications as modified (§8.2).
- No implication of endorsement (§17, §18).
- No added restrictions on rights this license grants (§19).

### Expressly excluded

- Any obligation to disclose the distributor's own source code (§9).
- Any warranty (§20).
- Any obligation to provide support or updates (§22).
- Any right to collect, sell, disclose, or process user data (§12).
- Any trademark rights beyond truthful attribution (§17).

### Term

- Per-violator automatic termination on material and intentional breach, with
  downstream recipients' rights preserved (§21).
- Severability (§24).
- No waiver (§25).
- No retroactive amendment by informal statement or README comment (§26).
