## What is LGPT?

**LGPT** is a free, flexible software license that gives you maximum freedom while preserving creator attribution.

One line: *Use it anywhere — open or closed source, commercial or personal — just give credit.*

---

## ✨ Key Freedoms

| Freedom | Description |
|---------|-------------|
| 🔄 **Use Freely** | Use for any purpose — personal, commercial, educational, or governmental |
| ✏️ **Modify & Fork** | Change the code, create forks, no permission needed |
| 📦 **Distribute** | Share original or modified copies, free or paid |
| 💼 **Commercial Use** | Sell products, services, or support that use the software |
| 🔒 **Keep Code Private** | No requirement to open-source your own proprietary code |
| 🛡️ **Privacy Respected** | No mandatory telemetry, tracking, or data collection |
| 📜 **Attribution Required** | Preserve copyright notices and credit the original creator |

## 🚀 Quick Start

Using LGPT in your project is simple:

1. **Copy** the [`LICENSE`](https://github.com/Ali-A-2026/LGPT/blob/main/LICENSE.txt) file into your project root — do not modify it
2. **Credit** the license in your project's documentation, About dialog, Credits, or NOTICE file:

